Design plan · before anything gets built

AgentRoom

A supervision position for fourteen agents working in parallel. It answers one question — who is blocked on me? — and treats everything else as secondary.

Where I stand

Your brief rules out warm cream with terracotta, and the design system bound to this project is warm cream with terracotta. I'm not abandoning it — I'm inverting it. Organic's warm neutral ramp goes deep and becomes the paper; its sage becomes the voice of ordinary work; its terracotta is spent in exactly one place, on one state, as a fill rather than an accent. Nothing else in the room is saturated. That is a different garment cut from the same cloth, and it happens to solve the state problem for free.

I couldn't reach the attached agent-room folder from here, so state names and roles come from your brief and the three screenshots. If the real spec names them differently, that's a find-and-replace, not a redesign.

Assuming: fourteen agents, both themes designed properly, a simulated live stream, and the seven row actions you picked — reply, approve, pause, reassign, fork, open terminal, mark reviewed.

The state system
the actual answer

The lever is figure and ground, then luminance decay — not hue.

Needs input is the only state that is filled. Every other row is ink on paper; a blocked row inverts into a solid plate. Figure/ground inversion is the loudest signal available and it costs no colour, so it doesn't degrade as the roster grows: six plates means six things need you, which is the truth. The other four states are the same neutral at descending ink strength — 100, 74, 50, 32 percent — so the roster reads top-to-bottom as a fade. Bright means yours. Dim means handled.

Role, the second channel

Role never gets a colour, because colour is spoken for. Role is a two-letter monogram in a fixed slot at the row's left edge, set in the code face — and critically it inherits the row's ink strength, so it rides on state rather than competing with it. A dim role is a dim row. Seven letterforms are learned in a day and then read faster than any icon.

Signature
the Rail

One narrow column, full window height, between the roster and the stream. Every agent owns a permanent lane in it. When an agent emits, a tick appears in its lane at now and drifts downward as time passes — so the rail is a strip chart of the whole room, newest at the top, the day accumulating below.

It does four jobs with one gesture: you see the room is populated and working; you see who's been grinding versus who just woke; you learn where each agent lives spatially; and by mid-afternoon the day is a visible record you can scroll back through. A tick turns terracotta at the instant an agent blocks — so a question announces itself on the rail before you've looked at the roster.

Under reduced motion it stops drifting and renders the same history as a static chart. It is the only moving thing in the interface.
